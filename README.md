Task 1: Hangman Game

A word-guessing game developed using Python. The player guesses a hidden word one letter at a time and has six attempts to find the correct word.

Features

- Random word selection
- Hangman drawing
- Input validation
- Win and game-over messages

Technologies Used

- Python
- Random module

Python Concepts

- Variables and lists
- Loops and conditional statements
- Functions
- User input and validation

How to Run

Run this command from the repository's root folder:

"python Task-1-Hangman/hangman.py"
